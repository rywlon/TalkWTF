# Phase 19 · Voice to Agent 与界面更新

2026-11-22。按本次用户指令推进 UI 更新和语音直达 Agent。

## 目标
让用户留在当前思路中，通过独立热键录音、本地转写，将文本交给指定 Agent。现有听写和翻译保留。

## 范围
- 更新主窗口、导航与概览，减少分组框嵌套，突出语音入口、快捷键和工作流。
- 独立 Voice to Agent 热键；录音开始时固定目标，完成后直接交付；展示交付结果与失败信息。
- Agent 连接方式依据用户指定的首个目标确定。仅建立明确支持的连接，不假设任意桌面聊天支持后台投递。

## 非目标
不新增自建云、账号、遥测，不改写 ASR，不把未验收功能描述为历史成果。

## 验收
- 原有听写、翻译与历史功能可构建、测试。
- 新工作流独立配置，未设置目标时给出明确提示。
- 语音不会误粘贴到当前工作窗口；交付失败可恢复文本，不自动重复发送。
- 交付过程中不激活目标窗口或切换前台。
- 浅深主题适配，主窗口在最小尺寸下可用。
