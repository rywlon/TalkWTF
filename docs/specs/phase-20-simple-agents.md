# Phase 20 · 无需技术配置的 Agent 添加流程

用户要求：删除概览的“使用统计与个性化”整块；普通用户无需理解接口或命令即可使用 Voice to Agent。

## 范围与验收
- 删除该分组和它专属的渲染方法，保留今日、最近活动及服务状态。
- 内置 Codex 自动检测；用户只选 Agent、工作文件夹和热键。
- 每个语音 Agent 使用独立会话，首次任务创建，后续自动续接；不假装能接管任意桌面聊天。
- 自动管理命令与会话编号；显示 Agent 回复，运行失败保留输入。
- 原有接口/命令配置保留为“高级连接”，不在默认使用路径出现。
- 自动检测、命令参数与会话回执解析通过测试；应用构建和界面检查。

## 进度
1. [completed] 精简概览，完成自动检测、内置 Codex 接入及后台测试。
2. [cancelled] 文件夹/登录向导被用户后续指定的 Phase21 提示词配对流程替代。
3. [completed] 后台测试和构建已通过；最终用户界面验证记录在 Phase21。
