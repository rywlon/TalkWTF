# Phase 21 · 由 Agent 完成配对

用户指定流程：连接 Agent → 选择 Agent → 复制简短提示词 → 粘贴到该 Agent → Agent 自动连接。

## 实现
- 默认入口替换为 Codex / Claude Code / OpenCode / Cursor / 其他本地 Agent 的选择与提示词。
- 提示词引用应用生成的本机连接说明；说明包含当前版本的配对命令和适配协议。
- 一次性本地配对请求（10 分钟有效）和响应文件；随机令牌、请求绑定、选定客户端身份校验。
- 应用自带 `connect-agent` 命令，Agent 无须安装依赖；同一可执行文件处理 CLI 后退出，不启动 UI。
- Codex 必须提供明确的现有会话编号；其他 Agent 提供当前会话可用的本地接收入口/适配命令。不能接入时明确报告，不冒充连接成功。
- 只有配置验证、响应校验和持久化完成后显示已连接。取消/过期后响应无效。
- 不自动粘贴或发送到用户其他聊天；由用户复制粘贴提示词。

## 进度
1. [completed] 配对协议、内置命令和验证测试。
2. [completed] 选择 Agent、复制提示词、等待连接与完成状态；实际界面收到本机测试回执并自动推进到热键设置。
3. [completed] Debug 构建通过；344 项核心与 6 项 FFI 测试通过；配对/传输测试通过；实际 UI 验证选择、复制、等待、回执确认、热键引导和取消。

默认不再使用 Phase20 的工作文件夹/登录向导。概览“使用统计与个性化”保持删除。

## 适配边界

选项标识用户当前使用的客户端，不表示所有客户端版本已通过实测。自动配对校验会话配置；具体接收能力由 Agent 用自身支持的接口/适配器建立。当前验证覆盖本机配对、原样投递、状态持久化和回执；尚未进行各厂商客户端的真实语音端到端验收。独立复查未发现确定的重要配对生命周期问题。

最终测试版：`macos/build/Debug/TalkWTF.app`。临时配对目标与待配对请求已清理；没有向真实 Agent 发送任务，没有授予麦克风/辅助功能权限。复制测试用的提示词已取消，不能继续用于配对；用户应在连接窗口生成新的提示词。
